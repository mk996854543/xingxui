# 星绘次元前端

使用 React、TypeScript、Vite、React Router、Node.js 和 npm。当前包含网站介绍页、人物与背景轮播、浏览器本地模拟登录与注册。工作台只保留用于验证登录跳转的入口提示，未实现制作界面或业务接口。

预览时可在登录弹窗点「填入演示账号」，或使用示例邮箱注册本地账号。演示状态仅保存在当前浏览器，不发送邮件，也不接入真实身份验证。

## 介绍页美术素材

以下素材以附录图 A 为风格参考，使用内置图像生成工具分别生成，再编码为 WebP。文档原图不作为网页图片使用；品牌文字、标识和操作控件由网页独立渲染。

| 主题 | 背景图生成方向 | 人物图生成方向 |
| --- | --- | --- |
| 月下樱庭 | `moon-background.webp`：横版半写实国风动漫，左侧留深紫空间，右侧满月、古建筑、灯笼与粉樱；无人物和文字。 | `moon-character.webp`：紫粉汉服的成年角色回眸，飘发、樱花发饰和月光轮廓光；真实透明底。 |
| 花间初晓 | `dawn-background.webp`：横版国风黎明，左侧暗紫留白，右侧粉桃天际、山间楼阁与梅花；无人物和文字。 | `dawn-character.webp`：粉白汉服的成年角色回眸，梅花饰、飘带与暖色晨光；真实透明底。 |

上表四张图均在 `public/images/landing/`。同一目录还包含用户提供的六张竖版插画，按附件顺序追加为「花间月」「云水清欢」「山海秘境」「九天玄境」「春阁听风」「花间醉」。竖图保留原比例，用桌面和手机各自的取景展示。

首页依次轮播这八个主题。每次换图后独立抽取 **600～1200 秒（10～20 分钟）** 的停留时间，手动换图也重新抽取。标签页隐藏或手动暂停后保留剩余时间；恢复时接着计时。下一张预先加载并解码，主题以 1 秒淡入淡出，文字和按钮不动。

## 本地开发

要求 Node.js 22.22.0 或更高版本，并使用 npm。首次拉取后，在仓库根目录执行：

```powershell
npm ci
npm run dev
```

开发地址：[http://127.0.0.1:5173/](http://127.0.0.1:5173/)；在启动服务的终端按 `Ctrl+C` 可停止服务。如果 Windows PowerShell 的执行策略阻止运行 `npm.ps1`，请用 `npm.cmd` 执行相同命令。

## 类型检查与构建

```powershell
npm run typecheck
npm test
npm run build
npm run preview
```

`npm run build` 先执行 TypeScript 检查，再将产物写入 `dist/`。构建完成后可在 [http://127.0.0.1:4173/](http://127.0.0.1:4173/) 本地预览。正式部署到静态服务器时，需将未匹配到静态文件的页面请求回退到 `index.html`，以支持直接打开前端路由。

## 目录

| 目录 | 用途 |
| --- | --- |
| `src/assets/` | 通过源码导入、由 Vite 处理的资源 |
| `src/components/` | 公共组件 |
| `src/layouts/` | 公共布局 |
| `src/pages/` | 页面 |
| `src/router/` | 路由配置 |
| `src/styles/` | 全局样式 |
| `src/hooks/`、`src/utils/`、`src/types/` | 公共 Hooks、工具函数和类型 |
| `public/images/`、`public/icons/` | 按原路径提供的图片和图标 |

新增页面放入 `src/pages/`，并在 `src/router/AppRouter.tsx` 注册路由。项目文件使用 UTF-8，页面语言为简体中文，TypeScript 类型检查优先输出中文诊断。
